# Good Stock Value Investing

基于李大霄“做好人、买好股、得好报”三层投资哲学与巴菲特逆向价值投资理念，评估企业长期价值并校准投资行为模式。

## When to Use

- 用户询问某家公司或股票算不算“好股”或“好人股”，是否值得长期持有。
- 用户在市场暴跌恐慌（想割肉）或狂热暴涨（想追高、加杠杆）时寻求投资决策或心理按摩。
- 用户希望从“社会价值创造 + 财务基本面 + 投资者行为心理学”三个维度全面审视一项投资。

## Steps

### 1. 第一层评估：买好股（社会价值定性）

评估标的公司是否符合“好股”的本质标准：

- **核心判准**：世界因为这家公司的存在，是变得更好还是更差？
- **排雷检查**：剔除纯粹靠概念炒作、讲故事、庄家坐庄拉抬或损害社会利益的公司。
- **价值点识别**：分析该公司每卖出一份产品、每服务一个用户，是否在真实解决问题、持续为社会创造正向价值。

### 2. 第二层评估：得好报（财务与数学复利）

将“让世界更好”的人话翻译为严谨的财务语言，验证股东是否能通过复利“得好报”：

- **真实盈利与ROE**：利润是否来自主营业务的真实价值创造，净资产收益率（ROE）是否长期稳健。
- **现金流与分红**：自由现金流是否充沛，公司是否具备持续分红或回购的能力与意愿，让股东真实分享价值创造的洪流。
- **护城河**：商业模式是否具备可持续的竞争壁垒，能否跨越周期。

### 3. 第三层评估：做好人（投资者行为与择时校准）

审视当前的市场位置与用户的心态行为，因为“投资是人格的延伸”：

- **行为模式自检**：提醒并核查用户是否存在“想占便宜的追涨杀跌”、“想不劳而获的加杠杆赌明天”或“眼红暴涨题材”的行为。确立“不追高、不杠杆、不眼红、有耐心”的好人行为模式。
- **逆向周期位置判断（看方向而非苛求精准时机）**：
  - **底部区域（别人恐惧时）**：若优质标的处于大周期底部区域，鼓励做情绪稳定器，看重3年维度的方向正确，而非纠结早三个月的短期时机，切勿在绝望底部割肉。
  - **顶部区域（别人贪婪时）**：若市场处于狂热阶段或估值泡沫化，坚决提示风险、劝阻追高，不做接盘侠。

### 4. 输出结构化评估报告

向用户输出包含以下四个模块的评估结论：

1. **【好股定性：社会价值】**：一句话总结世界因它变得更好还是更差，及核心社会价值支撑点。
2. **【好报验证：财务复利】**：从ROE、现金流、护城河与分红角度给出基本面成色评估。
3. **【好人修行：操作与心态建议】**：结合当前估值/周期位置，给出“不追高、不杠杆、长期陪伴”的具体行动建议。
4. **【价值寄语】**：以朴素、清醒且温柔的语言总结核心结论（并附带投资风险免责声明）。

## Gotchas

- 不要将“做好人、买好股、得好报”当成玄学或道德说教来输出，必须向用户拆解其背后的底层逻辑：买好股是社会价值定性，得好报是财务复利的数学必然，做好人是站在概率正确一边的行为模式。
- 在讨论市场底部或顶部时，强调“模糊的正确（底部/顶部区域的方向）”远比“精准的时机（猜具体点位）”更重要。
- 始终附上合规免责声明：分析仅基于公开资料与价值投资框架，不构成具体买卖指令，投资有风险，决策需自主。
