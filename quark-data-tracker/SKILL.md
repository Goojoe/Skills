# Quark Data Tracker

用于统一记录、分类管理并快速检索用户在网盘（以夸克网盘为主）中存放的各类软件配置、应用数据及重要文件目录，支持随时扩充新的分类与数据目录。

## When to Use

- 用户询问某个软件、系统配置或应用的数据存放在哪个网盘、哪个目录（如“EhViewer 的数据在哪？”、“我的 Windows 软件配置在哪个网盘文件夹？”）
- 用户在网盘（如夸克网盘等）中检索特定数据或配置文件夹路径
- 用户提供新的软件数据或目录路径，要求记录、新增、修改或删除网盘数据条目

#### 分类1：安卓软件数据

| **EhViewer** | 夸克网盘 | 配置文件-软件数据 | 安卓端软件配置与数据 |

## Core Workflow

### 1. 检索与显示网盘数据目录

1. 当用户询问某个软件或文件在网盘中的存放位置、或查看数据列表时，在对应的分类表格中检索。
2. **输出格式**：
   - 第一步：先用独立的代码块展示网盘文件夹名方便复制。
   - 第二步：用表格显示数据列表。

### 2. 新增或更新数据目录

1. 当用户提供新的数据和存放目录时，提取关键字段：**数据类别/分类**（如安卓软件数据、Windows软件数据、其他数据）、**软件/项目名称**、**网盘平台**、**网盘文件夹/路径**及**备注**。
2. 保持原样记录文件夹名称（严格按照原文，不自行缩写或改动），将新记录填充至对应的分类表格中。
3. 如果用户提供了新的大类或分类（如“数据2”或“分类3”），自动新建对应的表格结构进行记录。

## Gotchas

- 路径与文件夹名称严格按用户给出的原文记录（如 `配置文件-软件数据`），确保在网盘中搜索一致。
- 聚焦“网盘数据与目录存放检索”，保持分类清晰，录入新条目时归入相应的大类与分类下。
